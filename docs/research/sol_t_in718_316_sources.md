## Reproduction and access

`sol_t_in718_316_checks.json` enumerates **raw PDF page extraction**, raw-byte hashes, named captured endpoint values and anchored metadata checks for the integration check script. Use `pdftotext -enc UTF-8 -raw -f PAGE -l PAGE FILE -`; positional table errors need the stated visual check, not a second copy of a hand-entered ledger. The original canonical Pottlacher hash matches the worktree archive; no mutated export was used. Hashing authenticates equality to these archived bytes, not publisher origin, physical correctness, method pairing or upstream papers. Unknown origin/cycle/criterion is intentionally not transformed into an automated pass.

No named forbidden paper, measured dataset, measured rows, bands tool or frozen validation data was opened. Later checks isolate PDF21's property table only. Pichler source property/method/uncertainty pages and allowed DTA/microstructure papers were inspected. The original A2/A3 blind-access limitations, including the separately reported MP04 measured-track exposure, remain; this review is source transcription work, not a clean blind physical validation.
