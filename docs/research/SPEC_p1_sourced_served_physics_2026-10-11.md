### 4.2 Chosen form for the depth: `depth = max(d_iso, e_kh)` for every kernel

The max is Fabbro's reading: below the threshold the pool is the conduction pool, above it the keyhole depth (Eq 6 to 7, Sec 3). `keyholeDepthModel.modelId` becomes `FABBRO_MODEL_ID` for every kernel, `basis` becomes `FABBRO_BASIS` (section 7). `pecletInFitRange` is now meaningful for Rosenthal results too: the leg is served outside Pe 2 to 10 for every kernel (most LPBF conditions, INV 0.3), and the flag plus the basis sentence say so. Constants: none new. Drift: 2.4.

### 4.3 Chosen form for the fallback floor: `d_iso = half_w` (ratio 1.0)

The fallback (TS 423 to 440) runs only when the field has no resolvable liquidus extent and is served as `heuristic-width-fallback`, "not resolved". The served Rosenthal field (TS 281 to 292) depends on `R = sqrt(x^2 + y^2 + z^2)` and `x` only, so it is symmetric under `y <-> z`: at any station its liquidus half width and depth are equal. The floor for a Rosenthal substitute is therefore `d_iso = half_w` (Rosenthal 1946, primary not in library; the symmetry is visible in the served code and is tested, test 6). For distributed sources depth is below half width: King 2014 Sec 5.2 (`king2014.pdf` p.2921) defines keyhole mode by `d > w/2`, so a conduction pool has `d <= w/2`; Hofmann 2026 Sec 2.2 (conduction up to d/w 0.5); Cunningham 2019 SM p.3 (d/w about 0.5 at the melt pool transition). Ratio 1.0 is then an upper bound for Eagar-Tsai and Goldak fallback rows; acceptable because the branch is labelled not resolved, and the extent note gains "depth set equal to the half width (Rosenthal symmetry), an upper bound for distributed sources". Drift: fallback rows only, 2.1 to 2.8x.

### 4.4 Process map proxy (in scope)

Width cell: `eff_p = A_flat P` for every cell (item A). Depth cell: `d = max(0.5 w, e_kh(P, v))` with the same leg (ramped, same gate) and the conduction bound `0.5 w` (King 2014 Sec 5.2 criterion `d > w/2` marks the point where the leg takes over). The Tang lack of fusion test reads the new `d`. Cost: 49 closed form evaluations. Drift: every grid cell's `width_um` and `depth_um` for every alloy except copper (BLAST 5.4); regime labels and colors do not move (enthalpy only); lack of fusion cell classes can move and are counted in the snapshot.
