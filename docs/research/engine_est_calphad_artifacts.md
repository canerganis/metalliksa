## Ti CALPHAD: final separate diagnosis and correct repair

This is an incompatible database/model representation for the full chemistry, not a numerical minimizer failure or a missing kinetic model. Relevant live paths are `calphad_solver.resolve_database`, `solve_pycalphad_equilibrium`, `_EquilibriumRunner`, and `python/databases/COST507.tdb`.

1. The full sweep chemistry contains Ti, Al, V, C, Fe and O. `resolve_database` checks requested element coverage and Ti-base scope, without dropping species. COST507 contains all these elements. `mc_ti` does not contain C, Fe or O and is explicitly opt-in; it is not a replacement for this request.
2. COST507 lines 824-839 declare `BCC_A2` as `(substitutional elements)1(B,C,N,VA)3` and `BCC_B2` as `(same elements)0.5(same elements)0.5(VA)3`. Line 1560 attaches `BCC_B2 DIS_PART BCC_A2`. The active substitutional sets agree for this chemistry. The active interstitial sets are **C+VA versus VA**. O is in the overall request but is not an A2/B2 interstitial species in this file; blaming oxygen for this particular mismatch is incorrect.
3. The solver includes all database phases except explicitly catalogued exclusions and supplies all requested components plus VA to pycalphad. Installed pycalphad 0.11.2 rejects the ordered-model construction in `_extend_ordered_if_subset_of_disorder`, before equilibrium: "Order (BCC_B2) and disorder (BCC_A2) model must have no interstitial sublattice or a single matching one". Carbon-free construction passes because both active interstitial sets then contain VA only. This is a diagnostic control, not permission to change the specimen.

**Correct repair contract:** provide a versioned, compatible Ti-Al-V-C-Fe-O thermodynamic assessment/model. For the existing partitioned A2/B2 formulation, the ordered and disordered phases must share active interstitial species and the same interstitial-to-substitutional site ratio, and the ordered model must recover A2 Gibbs energy when substitutional ordering vanishes. A compatible extension would use `(S)0.5(S)0.5(B,C,N,VA)3` together with the existing `(S)1(B,C,N,VA)3`, and a source-supported partitioned energy specification. It must define how the vacancy-only ordering energy extends to carbon occupancy. Either obtain that extension from an assessed source or explicitly derive and review a new model, label the ordering/interstitial assumptions and process/composition transfer Tier 2, and record its scientific provenance. No unique carbon-ordering parameterization can be inferred from the mere constituent lists.

The open [pycalphad partitioned-model implementation](https://pycalphad.org/docs/latest/_modules/pycalphad/model.html), `_partitioned_expr` and `atomic_ordering_energy`, provides the construction `G_dis(xbar,yI) + G_ord(y0,y1,yI) - G_ord(xbar,xbar,yI)` and corresponding site-ratio/constituent checks. The linked latest documentation is a development build; the version-specific evidence here is the inspected installed `Metalliksa-1/.runtime/lpbf-win-py312/Lib/site-packages/pycalphad/model.py` (0.11.2), especially lines 63-102, and the actual model-construction check. This is mathematical model support; it does not supply missing assessed carbon-ordering interactions. The primary [COST507 report](https://www.opencalphad.com/databases/CGNA18499ENC_001.pdf), Thermodynamic Modelling section, documents the assessment framework; no new Ti multicomponent fit is authenticated here.

**What is insufficient:** adding C to the B2 constituent declaration makes the installed library construct a model and recover the disordered limit in the checked states, but that alone authenticates no carbon-ordering assessment. Removing C, excluding B2, detaching the partitioning hint or choosing `mc_ti` alters the requested chemistry or thermodynamic model. These may only be separately named, explicitly chosen restricted calculations, never silent repairs. Catching the exception is useful presentation, not the scientific fix. An equilibrium phase fraction must not be presented as an LPBF retained phase fraction.

**Acceptance for the implementer:** preserve full input composition and report effective conditions; bind a new database/model hash; retain assessed parameter provenance; construct every admitted phase for the full UI chemistry; test equal-sublattice disordered limits with positive carbon occupancy and finite T; test carbon-free continuity and derivatives/chemical potentials; compare binary assessment limits and trusted independent equilibrium results; test phase selection/cache identity/refusal transport. The research check below proves only the first structural cause and selected energy limits, not the latter thermodynamic acceptance.

**Current quantity/alloy ceiling:** full-chemistry Ti equilibrium phase fractions, transition temperatures, chemical potentials and Scheil results remain no-value until a compatible model exists. After either a compatible assessed model or the explicitly derived/reviewed partitioned extension above, with disclosed assumptions and multicomponent extrapolation, Tier 2 is the attainable ceiling for these Ti estimates here. AlSi10Mg/IN718/316L did not have this construction failure in the sweep; their database/process domains still need independent per-result assessment, and this diagnosis does not promote them. IN625 has no sweep composition and is not synthesized. No Tier 1 sensitivity claim is made.
